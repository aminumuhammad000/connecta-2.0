# Connecta Website Image Starter Pack

This pack contains a manifest of real stock-photo references, meaningful filenames, and a downloader script.

## Important
The photos themselves could not be bundled in this environment because external image downloads are blocked. Run the downloader on a computer with internet access to fetch the JPEGs into the `images/` folder.

## How to download
1. Extract this ZIP.
2. Open a terminal in the extracted `connecta_image_pack` folder.
3. Run: `python3 download_images.py`
4. The photos will be saved into `images/`.

## Editing with AI
Keep the original person, face, hands, tools, and work activity unchanged. It is fine to adjust lighting, crop, color balance, or distracting background elements. Do not make stock-photo subjects appear to be actual Connecta providers. For provider profiles, use real photos submitted by the providers with permission.

## Source and licensing
The manifest includes each source page and photographer name. Pexels labels these photos as free to use, but check the current Pexels licence and the individual page before commercial publication. Retain attribution/source records internally.

## Naming convention
Filenames use descriptive service names so developers and AI coding tools can understand where each image belongs. Use lowercase, underscores, and `.jpg`.
