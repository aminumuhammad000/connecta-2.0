CONNECTA WEBSITE BRAND ASSETS

Brand colors:
- Primary blue: #1A73E8
- Success green: #10B981
- Accent yellow: #F59E0B
- Text/dark: #111827
- Background: #F8FAFC
- White: #FFFFFF

Folders:
- favicon/: favicon.svg, favicon.ico, PNG favicon sizes
- header/: horizontal Connecta wordmark/logo PNG sizes and header icon SVG
- app-icons/: light/dark/blue app icons, PWA manifest, icon sizes
- social/: social profile avatars
- svg/: scalable vector symbol and wordmark files
- docs/: HTML snippet for website <head>

For websites, SVG is best for the header logo because it stays sharp at any size.
Use favicon.ico or 32x32 PNG for browser tabs. Use apple-touch-icon 180x180 for iOS.
Update the paths in website-head-snippet.html to match your actual hosting folder.
